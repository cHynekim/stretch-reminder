아직 배포된 버전이 없어요. 곧 올라올 예정이에요!

처음 설치할 때 경고가 떠요

Mac

  1. .dmg를 열고 앱을 응용 프로그램 폴더로 끌어다 놓아요.
  2. 앱을 처음 열면 "확인되지 않은 개발자" 경고가 떠요. 완료를 눌러 닫아요.
  3. 시스템 설정 → 개인정보 보호 및 보안 맨 아래의 그래도 열기를 누르고 다시 열어요.

Windows

  1. 설치 파일을 실행하면 "Windows의 PC 보호" 창이 떠요.
  2. 추가 정보 → 실행을 눌러 설치해요.

한 번 설치하고 나면 다음 버전부터는 앱 안에서 자동으로 업데이트돼요.
